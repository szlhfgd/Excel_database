# 04: SQL 模式端到端

**What to build:** 用户在界面切换至 sql 模式、手写 SQL 并执行，结果以整行、全量（不截断）展示，可下载 CSV，空结果给友好提示。打通「模式切换 → SQL 执行 → 结果 Tab → 导出」完整路径，本身可独立验证。

**Blocked by:** 02（文件导入 + 侧边栏表管理）

**Status:** ready-for-agent

- [ ] 主区域提供模式切换（hybrid / ask / sql）与 SQL 输入区
- [ ] 执行用户 SQL，返回命中整行的全部列，不限制行数
- [ ] 结果以 Tab 展示，顶部有「下载 CSV」按钮
- [ ] 结果为空时显示友好中文提示，不抛红错
- [ ] pytest 验证数据库执行层对给定表返回期望行
